# Chicken activity push notification

Sends an FCM push to every viewer of a shared chicken dataset when the owner
records a sale (`cock_sales`, `batch_sales`) or an expense (`expenses`). The
`notify_chicken_activity` triggers call it once per INSERT statement.

Deploy with JWT verification off — the caller is a database trigger, not a
signed-in user, and it authenticates with `x-notify-secret` instead:

```sh
supabase functions deploy notify-chicken-activity --no-verify-jwt \
  --project-ref fyyrgwohjgvsmwqgxiga
```

## Secrets

`CHICKEN_NOTIFY_SECRET` is generated by the migration and lives in Vault. Read
it once and hand the same value to the function:

```sql
select decrypted_secret from vault.decrypted_secrets
where name = 'chicken_notify_secret';
```

`FCM_SERVICE_ACCOUNT` is the Firebase service account JSON, verbatim: Firebase
Console → Project settings → Service accounts → *Generate new private key*.

```sh
supabase secrets set \
  CHICKEN_NOTIFY_SECRET=the_vault_value \
  FCM_SERVICE_ACCOUNT="$(cat service-account.json)" \
  --project-ref fyyrgwohjgvsmwqgxiga
```

Rotating the Vault secret means setting the new value here too; until then the
function answers 403 and no push goes out (the write itself still lands).

## iOS

Push on iOS also needs an APNs authentication key (`.p8`) uploaded under
Firebase Console → Project settings → Cloud Messaging, and the *Push
Notifications* capability on the Runner target in Xcode.

Phần mint OAuth token và gọi FCM nằm ở [`../_shared/fcm.ts`](../_shared/fcm.ts),
dùng chung với [`summarize-storm-news`](../summarize-storm-news/README.md) —
sửa file đó thì deploy lại cả hai function.
